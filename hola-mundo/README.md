# 👋 Hola Mundo molón

Una página web "Hola Mundo" con estilo, creada con Kiro.

## ✨ Características

- Fondo con degradado animado y "blobs" flotantes difuminados.
- Tarjeta central con efecto glassmorphism.
- Emoji que saluda con animación.
- Botón que cambia la paleta de colores y lleva la cuenta de saludos.
- Diseño responsive para móvil y escritorio.

## 🚀 Cómo usarla

Abre `index.html` en tu navegador. No necesita dependencias ni build.

## 📁 Estructura

```
index.html   # Marcado de la página
styles.css   # Estilos y animaciones
script.js    # Interacción (cambio de color, contador, emojis)
```
